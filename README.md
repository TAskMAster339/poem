# Сборник сочинений Дмитрия Гришко

Статический литературный каталог, опубликованный через GitHub Pages.

## Добавление произведения

Создайте HTML-файл произведения и замените пустое состояние в нужном списке в `index.html`:

```html
<li>
  <a href="works/story.html">
    <span>Название произведения</span>
    <em>2026 · рассказ</em>
  </a>
</li>
```

## Локальный запуск

```bash
python -m http.server 8000
```

Сайт будет доступен по адресу `http://localhost:8000`.
